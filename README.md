# 中土远征 · v0.7.3 中文卡图与剧本释义验收版

## 打开与测试

解压后双击 **index.html**。不需要 npm 或服务器。基础版73种英雄与玩家牌的中文卡图已内置，可以离线显示；必须完整解压并保留assets文件夹。其他图片仍需要联网访问 RingsDB 与 Hall of Beorn。

首页新增“规则书预组牌 · 开局测试”，可直接选择领导、战术、精神或知识预组牌。每个按钮都创建单人“穿越幽暗密林”，使用固定种子12345，方便重复核对。

1. 桌面放置真实英雄，显示数值、初始资源0、伤害0及重置状态。
2. 程序生成并洗混30张玩家牌库，抽6张起始手牌，剩余牌库24张。英雄不进入抽牌牌库。
3. 查看桌面手牌后，选择保留或整手调度一次。调度将原6张洗回，重抽6张且必须保留。
4. 点击“确认手牌并执行剧本设置”。此时才放置开局蜘蛛和古老森林道路。
5. 点击“收集资源、抽1张牌 → 计划阶段”。三名正常英雄各获得1资源，手牌变为7张，牌库剩23张。
6. 点击手牌的出牌按钮，选择合法目标及支付资源；响应窗口逐项处理。各玩家结束出牌并让过行动后，结算阶段2结束。详细验收步骤见 phase2-acceptance.md。
