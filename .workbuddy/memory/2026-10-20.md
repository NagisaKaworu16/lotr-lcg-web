## 深色界面问题（提交 8c02f9c）
- 用户截图是深色界面，疑问与内置预览不一致。页面只有米白浅色主题（style.css 无 prefers-color-scheme），深色来自浏览器端"强制深色模式"（Chrome auto dark / 夜间模式扩展），非两份代码。
- 对策：shell.html 加 `<meta name="color-scheme" content="only light">`，style.css `:root{color-scheme:only light}`，让渲染器保留原始配色；389 测试通过，已提交。
- 若用户仍见深色：检查浏览器深色模式设置或 Dark Reader 类扩展对本站关闭。

## 牌组导入/组卡器可行性调研（未动代码）
- 实测（本机代理 7899）：`https://ringsdb.com/api/public/decklist/<id>` 返回 JSON 且 `Access-Control-Allow-Origin: *`；`/api/public/deck/<id>` 与 `/api/public/decklists/` 均 404，牌组只有 decklist 端点。`/api/public/cards/` 也是 200 + CORS *。
- 牌组 JSON 结构：{ id, name, heroes:{code:count}, slots:{code:count}, sideslots, starting_threat, ... }。项目内部是 heroes:[code]、slots:{code:count}，只差 heroes 的形态，适配器约 10 行。
- 阻塞点：ringsdb.com 国内被墙（CORS 已允许，连不通才是关键）；离线单文件运行时需网络；快照只有基础版，扩展卡会报“未接入卡牌”。
- 现有底子（无需重写）：player-cards.js 已有 validateDeck（1-3英雄/3张上限/50张下限/领域警告/教学模式）、validateFellowship（跨玩家英雄去重）、importDeck/exportDeck；player-ui.js 已有组卡器 UI + localStorage `lotr-saved-decks-v1` + 保存后可在开局每人下拉里选。
- 建议路线：P1 文本牌表粘贴导入（离线最稳）→ P2 URL 导入+localStorage 缓存 → P3 组卡器补强（卡池过滤/实时校验/分享链接）→ P4 扩展卡池。
